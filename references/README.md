# Reference library

101 PDFs (604 MB) on clustering, from foundational textbooks to 2020s papers. The files live in
`~/Desktop/K-Means Clustering Books/` and are **not** in this repository — they are copyrighted
books and papers, and 604 MB has no business in git history. This index is committed so the
library is searchable from the editor even when the files are not open.

**Grouped by what they are for, not alphabetically**, because the question is usually "what does
the literature say about choosing k" rather than "where is that paper whose title I remember".

> **Note on reading them.** The folder is in iCloud Drive with "Optimise Mac Storage" on, so most
> files are placeholders with no local contents. `brctl download`, `cat` and `dd` all fail to
> materialise them from a terminal. To make them readable: open the folder in Finder, select all,
> right-click → **Download Now** — or turn off Optimise Mac Storage for iCloud Drive.

## How this library is used

Claims in the tool's report and documentation that come from the literature name their source in
the code, next to the thing they justify — Milligan & Cooper on range standardisation, Tibshirani
& Walther on prediction strength, Hennig on bootstrap Jaccard stability, Dolnicar & Leisch on
segments being constructed rather than discovered, Monti on consensus clustering, Kaufman &
Rousseeuw on reading a silhouette. Those citations were written from established results, and
this library is where they should be checked.

See [`STATE-OF-THE-ART.md`](STATE-OF-THE-ART.md) for what the tool implements today measured
against current practice, and which gaps are worth closing.
